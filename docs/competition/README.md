# 比赛材料管理

## 版本策略

同一套核心代码适配两个赛道，但材料分为两个版本，不直接复制粘贴。

### 创新赛道版本，工安智评

突出职业肌肉骨骼损伤风险、连续作业风险、产品闭环、企业价值和现场可视化演示。

### AI 应用挑战赛版本，ErgoAgent

突出 Agent 接收请求、规划任务、调用姿态和风险工具、检索人体工效规则、返回证据解释和用户追问闭环。

## 提交检查

1. 核对当届官网、所在赛区通知和组委会答复。
2. 确认参赛身份、团队信息、双赛报名资格和截止时间。
3. 应用方案中的每个数据、奖项、指标和技术声明都有来源。
4. 演示视频展示真实可运行程序，不只展示静态页面。
5. 代码、模型、数据和视频的许可证或授权记录齐全。
6. 开发日志、提交历史、实验记录和 AI 辅助制作标注齐全。
